# Gaslight Maps

Gaslight Maps is a world map for aerial surveys, field reports, and evidence-aware walking routes. Create an incident by searching for a place, using your location, or dropping a pin. Add an initial observation and photo, import streets, and add georeferenced imagery over the surveyed footprint. Field teams report what they find, and the app updates the shared passage network.

- [Open the web app](https://yourmapisgaslightingyou.us)
- [Web setup and operator guide](web/README.md)
- [Native iPhone setup and verification guide](ios/README.md)

Aerial coverage shows what was photographed. A candidate route reflects the passages currently reported open. Real emergency use requires validation with response teams.
